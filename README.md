# XAReviewer
# XAReviewer - 医疗影像查看器

XAReviewer是一个功能强大的医疗影像查看器，专门用于查看和分析DICOM格式的医疗影像序列，特别是DSA（数字减影血管造影）序列。

## 功能特性

### 核心功能

- **DICOM序列加载**：支持加载和显示各种DICOM格式的影像序列，包括CT、MR、XA、US等模态
- **多视图布局**：支持1x1、1x2、2x2、2x3、3x3等多种视图布局
- **窗宽窗位调整**：支持手动调整窗宽窗位，优化影像显示效果
- **伪彩色显示**：支持启用伪彩色模式，增强影像的视觉效果
- **图像缩放与平移**：支持鼠标滚轮缩放和拖拽平移
- **序列导航**：支持在序列中前后导航，查看不同帧的影像
- **同步控制**：支持同步缩放、平移、窗宽窗位和层面

### 高级功能

- **光谱CT支持**：支持加载和显示光谱CT数据
- **超声图像支持**：支持加载和显示超声图像，包括彩色多普勒
- **多帧DICOM支持**：支持加载和显示多帧DICOM文件
- **图像缓存**：实现了图像缓存机制，提高显示流畅度
- **测量工具**：内置测量工具，支持距离、角度等测量

## 系统要求

- **操作系统**：Windows 10/11
- **Python版本**：Python 3.7+
- **依赖库**：
  - PyQt5
  - numpy
  - pydicom
  - opencv-python
  - scipy
  - pynetdicom

## 安装指南

1. **克隆代码库**：
   ```bash
   git clone <repository-url>
   cd XAReviewer
   ```
2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
3. **运行应用**：
   ```bash
   python app.py
   ```


## 模块说明

### core/sequence.py

包含DSA序列处理的核心类，负责DICOM文件的加载、解析和图像处理。

### ui/widgets.py

包含UI相关的组件，如样式定义、测量工具和图像查看器。

### utils/helpers.py

包含各种辅助函数，如文件处理、日期时间处理、图像处理和配置管理。

### config/settings.py

包含应用的配置管理，负责加载和保存用户配置。

### app.py

主应用入口，包含主窗口类和应用逻辑。

## 使用指南

### 加载序列

1. 点击菜单栏的"文件" -> "打开序列"，或使用快捷键Ctrl+O
2. 在弹出的对话框中选择包含DICOM文件的目录
3. 等待序列加载完成，影像将显示在主窗口中

### 调整布局

1. 点击工具栏上的布局按钮（如"1x1"、"1x2"等），或
2. 点击菜单栏的"视图" -> "布局"，选择所需的布局

### 导航序列

1. 使用工具栏上的"上一帧"和"下一帧"按钮，或
2. 使用键盘的左右方向键

### 调整窗宽窗位

1. 在图像上按住鼠标左键并拖动，或
2. 使用鼠标滚轮调整

### 启用伪彩色

1. 点击菜单栏的"工具" -> "伪彩色"，或
2. 使用工具栏上的伪彩色按钮

### 测量工具

1. 点击菜单栏的"工具" -> "测量工具"
2. 在图像上点击鼠标左键开始测量，再次点击结束测量

## 配置管理

应用的配置文件存储在用户目录下的`.XAReviewer`文件夹中，名为`config.json`。配置包括：

- **UI配置**：主题、字体大小等
- **图像配置**：默认窗宽窗位、伪彩色设置等
- **视图配置**：默认布局、同步设置等
- **性能配置**：内存使用限制、线程数量等
- **路径配置**：上次打开的目录、导出目录等

## 故障排除

### 常见问题

1. **无法加载序列**
   - 检查目录是否包含有效的DICOM文件
   - 确保DICOM文件没有损坏
2. **图像显示异常**
   - 尝试调整窗宽窗位
   - 检查DICOM文件的像素数据是否正确
3. **应用崩溃**
   - 检查系统是否满足要求
   - 确保所有依赖库都已正确安装

### 日志信息

应用会在控制台输出一些日志信息，帮助诊断问题。如果遇到问题，可以查看控制台输出获取更多信息。

## 开发指南

### 代码结构

项目采用模块化设计，将不同功能划分为独立的模块：

- **core**：核心业务逻辑
- **ui**：用户界面
- **utils**：工具函数
- **config**：配置管理

### 代码规范

- 遵循PEP 8代码规范
- 使用清晰的命名规范，避免使用缩写
- 为所有公共方法和类添加文档字符串
- 使用类型提示，提高代码可读性

### 测试

项目使用Python的内置unittest模块进行测试。测试文件位于`tests`目录下。
